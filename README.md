# Code-Academy — Conference Management System

⚠️ **This project is currently under development.** Features and functionality may change as development continues.

A web-based Conference Management System built with ASP.NET Core MVC that helps manage conferences, including speakers, sessions, attendees, and schedules.

## Features

- Manage Conferences: Create and update conference details
- Speaker Management: Add and manage speakers and their profiles
- Session Scheduling: Organize sessions and assign speakers
- Attendee Registration: Register and manage attendees
- Role-based Access: Different views and permissions for admins, speakers, and attendees

## Technologies Used

- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap for UI styling
